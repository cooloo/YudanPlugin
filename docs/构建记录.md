## 兼容修复与边界

公共实现迁入插件后，原播放页出现五种 Compose 接口默认参数静态入口不匹配。对应调用显式补齐原默认参数，继续通过真实 ABI 核对；没有放宽缺失成员检查。程序输入从公共 Gradle 运行制品收集两个音乐实现，避免将仅编译的 R 类或宿主第三方库混入包。

最终 DEX 核对加入 Android 框架类，准确查找 `ComposeView.setId` 等继承成员。默认公开基线来自已核对的历史宿主最终制品，保留制品哈希及资源证据，仅提取 SDK 和第三方公共运行库；更换宿主时仍应重新导出核对。

本次独立 SDK 工作未操作 Android 设备、安装应用或验证真实账号播放。源码与构建成功不能代替宿主最终 APK、MuMu 页面、真实在线播放及车型验证。旧音乐包依赖宿主音乐实现，迁移后的宿主应安装对应新包后继续使用原数据。
