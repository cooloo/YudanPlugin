## 来源与改动

音乐实现基于 [xuqian-git/cloudmusic-car](https://github.com/xuqian-git/cloudmusic-car)（LGPL-3.0），在其基础上适配鱼蛋桌面插件接口，并调整插件生命周期、后台任务、缓存及媒体同步。

网易云接口与 weapi/eapi 加密实现沿用上游注明的 [missuo/kumone](https://github.com/missuo/kumone) 来源，保留相关声明。

通用 SDK 提供插件接口、运行管理及界面服务。第三方依赖按其上游许可证使用和分发。
