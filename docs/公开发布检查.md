# 公开发布检查

日期：2026-11-08。

## 许可调整

五个通用 SDK 模块、示例、音乐实现及工程自有构建配置统一声明 LGPL-3.0。根许可、模块许可、SDK Maven POM 和插件内许可信息同步调整。Gradle 包装器等第三方内容保留原有许可和版权；过去已经按 Apache-2.0 提供的副本，其授权继续有效。

通用 SDK 改为 LGPL 后，宿主静态集成 SDK 的分发方式需要另行满足 LGPL 第 4 条；允许替换音乐插件不等于能够替换宿主 SDK。本次工作没有审查或改造整个桌面产品的重新链接方案。

## 隐私和私有内容

| 类别 | 处理 |
| --- | --- |
| 官方及开发者签名私钥、密码、签名配置 | 保留在本机 `.local`，从 Git 和源码归档中排除，不复制旧版本历史 |
| 酷狗微信登录应用 `secret` | 与 `xuqian-git/cloudmusic-car` 指定提交在线比对一致，按要求原样保留，作为上游协议常量单独记录，不改造登录配置 |
| 本机 SDK 路径及编辑器配置 | 排除 `local.properties`、`.idea`、Gradle 缓存等 |
| 模拟器真实连接地址 | 从公开验证文档中移除 |
| 完整宿主资源转储 | 留在本机并排除公开交付，仅公开公共字号摘录及原始资源表哈希 |
| 桌面私有实现、私有车模插件、生产账号配置 | 不纳入本工程公开范围，检查公开源码是否引用宿主私有实现 |
| 官方公钥证书 | 保留 `docs/official-plugin-certificate.der`，供核对签名身份，不包含签名私钥 |
| 网易云、酷狗等上游协议常量和公钥 | 核对用途后保留；协议固定参数不是我们生产环境的账号或签名私钥，不应为脱敏而破坏协议实现 |
| 通用测试中的内网示例地址 | 保留通用示例，不代表真实设备连接信息 |

上游应用 `secret` 经用户确认来源并在线比对，核对提交见[许可归属](许可归属.md)。不将其表述为我们自己的账号凭据，也不宣称该公开常量具有保密性。本次没有修改登录业务或调用第三方管理接口。

本地扫描同时将已知签名密码与每个待公开文件逐字节比对，并检查私钥标记、常见访问令牌、个人绝对路径、真实内网地址和宿主私有实现引用。报告只记录文件位置、类别和哈希，不记录凭据值。自动扫描不能证明不存在所有形式的敏感内容，公开范围及命中项仍需结合用途核对。

## 上传准备

原工作目录使用 SVN。用于 Git 的导出目录仅包含经过核对的当前源码，不携带 `.svn` 或其他历史记录，避免把旧版本中的凭据带入新仓库。Git 上传目录放在本机 `build/git-preparation/` 下，不是新的源码维护来源；后续仍在本工程修改并重新导出。

准备阶段只初始化本地 Git 仓库并检查待加入文件，不创建提交、不配置远程、不推送。实际上传需要确定远程仓库地址。

运行入口：

```powershell
python tools/verify-source-tree.py
python tools/check-public-source.py
python tools/package-source.py --output build/git-preparation/distribution
```

源码归档、哈希清单、静态检查报告及待上传目录统一位于本机 `build`。不要直接上传原工作目录，也不要把本地配置放入公开归档。保留每个已发布插件的对应源码快照；本次准备的工作源码未重新编译，不应覆盖旧版插件对应源码。

## 验证边界

本次仅核对公开文件的完整 UTF-8、乱码、Python／JSON／XML 静态解析、许可一致性、源码归档及 Git 文件范围。修改的 Groovy 许可声明单独解析，完整 Gradle DSL 的既有解析限制与原文件比较核对，不将静态解析等同于构建成功。没有执行 Gradle、单元测试、Android 打包或设备验证；本次不重复宣称历史构建或运行结果证明当前改动可用。
